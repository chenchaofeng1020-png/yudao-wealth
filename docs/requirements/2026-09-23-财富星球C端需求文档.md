## 1. 概述

### 1.1 背景

我们想做的是一个面向投资理财人群的付费私享社群——「财不外露」星球。星主/合伙人等在星球里发布市场观点、交易策略、研报解读等内容，付费用户可以看全部内容、向星主团队提问。简单的说，就是知识星球类产品，但内容更聚焦在资产配置和投资实战上。

目前交互原型已经完成（wealth circle 原型），跑通了从介绍页、注册登录、开通会员到浏览内容、发帖互动的完整体验。现在需要在芋道（ruoyi-vue-pro）框架上做真实开发，尽可能复用芋道已有的会员、商城、订单、支付能力，降低工作量。

本档只写第一个版本要做的内容。课程、直播、专栏等板块属于二期，本文档不展开，二期启动时再单独出需求。

### 1.2 目标

- 用户能通过手机号注册登录，注册后即成为「星友」，可浏览公开帖子列表并点赞；付费开通会员后可查看帖子详情、评论、发帖、提问。
- 用户能购买「年度会员」商品，支付成功后自动成为「会员」，解锁星球内全部帖子详情、评论与提问。
- 会员及以上用户能向星主、合伙人、嘉宾公开提问，形成问答内容沉淀在信息流里。
- 管理方能在后台管理内容（置顶、上下架、审核会员发帖）和成员（调整角色分组），会员的开通、到期、退款全部自动化处理，不需要人工干预。

## 2. 角色与权限体系

### 2.1 五种角色的定义与获得方式

| 角色  | 获得方式       | 说明                                         |
| --- | ---------- | ------------------------------------------ |
| 星主  | 后台手动设置     | 星球所有者，管理权限最高，正常只有一个                        |
| 合伙人 | 后台手动设置     | 星主的管理帮手，后台管理权限与星主相同                        |
| 嘉宾  | 后台手动设置     | 受邀专家，发帖、评论、查看详情等权限与会员一致，可被提问；身份头衔与简介由管理方维护 |
| 会员  | 购买会员商品自动获得 | 年度付费会员，有效期 365 天                           |
| 星友  | 注册默认       | 新用户注册完成即为星友，仅可浏览公开帖子列表与点赞；会员到期或退款后回到星友身份   |

### 2.2 会员分组与角色的映射机制

角色的控制完全落在芋道后台的「会员分组」上，不在用户表上加新的角色字段。后台预置五个分组，分组与角色一一对应，用户所在哪个分组，前端就按哪个角色展示和鉴权：

| 会员分组 | 对应角色 | 进入方式                     |
| ---- | ---- | ------------------------ |
| 星主组  | 星主   | 后台手动调整                   |
| 合伙人组 | 合伙人  | 后台手动调整                   |
| 嘉宾组  | 嘉宾   | 后台手动调整                   |
| 会员组  | 会员   | 购买会员商品支付成功后自动加入；也可后台手动调整 |
| 星友组  | 星友   | 注册成功默认加入；会员到期/退款后自动回到此分组 |

几点说明：

- 芋道的会员分组本身是单选的，一个用户同一时间只在一个分组，这与角色互斥的业务语义天然一致，不需要额外开发。
- 星主/合伙人/嘉宾也可以手动放进会员组之外的其他分组，前端展示的角色徽章、权限判断全部跟随分组走。
- 后台「会员管理」里调整某用户的分组，用户下次刷新页面即按新角色生效。

| 操作           | 星友 | 会员 | 嘉宾 | 合伙人 | 星主 |
| ------------ | -- | -- | -- | --- | -- |
| 浏览公开帖子列表     | ✓  | ✓  | ✓  | ✓   | ✓  |
| 查看帖子详情       | ✗  | ✓  | ✓  | ✓   | ✓  |

| 编辑/删除自己的帖子   | —  | ✓  | ✓  | ✓   | ✓  |
| 评论           | ✗  | ✓  | ✓  | ✓   | ✓  |
| 点赞           | ✓  | ✓  | ✓  | ✓   | ✓  |
| 向星主/合伙人/嘉宾提问 | ✗  | ✓  | ✓  | ✓   | ✓  |

说明：星友是未付费的观望身份，只能浏览公开帖子卡片和点赞；点击「查看帖子详情、评论、发帖、提问」相关入口时，统一弹出开通会员弹窗（见 3.3）。

### 2.4 会员生命周期

会员的开通、续费、到期、退款全部通过「会员商品 + 订单 + 分组」自动流转，不需要人工在后台搬人：

- **开通**：用户支付会员商品订单成功后，系统自动把该用户加入「会员组」，角色变为会员，到期时间 = 支付成功时间 + 365 天。
- **续费**：会员在有效期内再次购买，到期时间在当前到期时间基础上顺延 365 天；已过期用户再次购买，视为新开，到期时间 = 支付成功时间 + 365 天。
- **到期**：后台定时任务每天检查一遍会员组内的用户，到期时间已过的，自动移出会员组、回到星友组，前端身份与内容权限随之降级。
- **退款**：会员商品订单退款成功后，立即移出会员组、回到星友组。若退款时用户已因该订单续期叠加过到期时间，到期时间不做回滚计算，直接降级（退款即视为放弃会员资格）。

**原型示意（会员状态流转）**：

```
                      +---------------------+
                      |      注册成功        |
                      |    (加入星友组)      |
                      +----------+----------+
                                 |
                     购买年度会员商品
                        支付成功
                                 v
                      +---------------------+
          +---------->|   会员（会员组）     |----------+
          |           |  到期: 支付时间+365天 |          |
          |           +----------+----------+          |
          |                      |                     |
    有效期内再次购买         到期（定时任务检查）      订单退款成功
    到期时间顺延365天              |                  立即降级
          |                      v                     |
          |           +---------------------+          |
          +-----------|   星友（星友组）     |<---------+
                      +---------------------+
```

会员到期前不做主动推送提醒（本期不做短信/消息通知），用户可在「个人中心」随时查看自己的会员到期时间。

### 3.1 介绍页（Landing）

未登录状态下打开星球网站，默认进入介绍页。介绍页承担「了解星球 → 产生信任 → 注册登录」的转化职责。

- 星球介绍区：星球头图、宣传语、星主介绍（头像、身份头衔、简介）、星球数据（成员数、内容数）。

### 3.2 注册/登录弹窗

介绍页点击【登录】/【立即加入】，或星球内任意需要登录的场景（如未登录状态点评论），都会拉起该弹窗。弹窗顶部有「注册」「登录」两个页签：注册需要填写昵称，登录只需要手机号和验证码。介绍页的【立即加入】默认打开注册页签，【登录】默认打开登录页签。

**原型示意（注册页签）**：

```
+------------------------------------------+
|                                    [X]   |
|         欢迎来到财不外露星球              |
|    [ 注册 ]   登录                       |
|                                          |
|   昵称 *                                  |
|   [  ______________________  ]           |
|                                          |
|   手机号码 *                              |
|   [  ______________________  ]           |
|                                          |
|   短信验证码 *                            |
|   [ ________ ]   [ 获取验证码 ]          |
|                                          |
|   [x] 我已阅读并同意《服务协议》与《隐私政策》 |
|                                          |
|            [     注 册     ]             |
|                                          |
+------------------------------------------+
```

**(1) 字段说明**

a. 昵称：仅注册页签显示，必填，2\~20 个字符，支持中文、字母、数字。失焦时校验格式与是否重名，红字提示"请输入 2\~20 字的昵称"或"该昵称已被使用，换一个试试"。注册完成后可在个人中心修改昵称、上传头像（见 3.10）。

b. 手机号码：必填，11 位数字。失焦时校验格式，格式不对在输入框下方红字提示"请输入正确的 11 位手机号"。

c. 短信验证码：必填，6 位数字。点击【获取验证码】向后端请求发送短信，按钮进入 60 秒倒计时；验证码 5 分钟内有效，输错不锁定，校验失败提示"验证码错误或已过期"。

d. 协议勾选：默认不勾选。未勾选时点击【注册】或【登录】，弹提示"请先阅读并同意《服务协议》与《隐私政策》"。点击协议名称可打开对应协议页面。

**(2) 提交逻辑**

点击【注册】时：

- 校验昵称、手机号、验证码，全部通过后创建会员账号（昵称使用用户填写值，头像为系统默认头像），并把用户加入「星友组」（注册默认星友）。
- 若手机号已被注册，红字提示"该手机号已注册，请切换到登录"。
- 成功后关闭弹窗，带着登录态直接进入星球主界面（3.4），并弹出欢迎提示"{昵称}，欢迎加入「财不外露」星球"。

点击【登录】时：

- 校验手机号与验证码，通过后登录进入星球主界面；若手机号未注册，红字提示"该手机号尚未注册"。
- 登录页签不显示昵称输入框，昵称、头像等资料沿用账号已保存的值。

● 异常交互说明：若验证码已过期或错误，不关闭弹窗，在验证码输入框下方红字提示，用户重新获取验证码后可继续提交。

### 3.3 开通会员

开通会员的入口有三处：介绍页的转化按钮（先注册再开通）、星球内点开帖子详情时弹出的开通会员弹窗、个人中心里的会员信息卡。三处入口最终都进入同一个开通流程。

**(1) 开通弹窗**

弹窗展示年度会员的价格与权益清单，本期只有一个档位，不需要做档位切换：

### 3.5 信息流与帖子卡片

信息流是星球主界面的默认视图，按时间倒序展示星球内全部帖子（官方发布内容 + 会员/嘉宾发帖 + 提问帖），每页 20 条，向下滚动加载下一页。

**(1) 发布框**

信息流顶部有一个发布框：左侧为当前用户头像，右侧为 placeholder"点击发表主题..."；发布框下方始终显示一排工具图标（表情、图片、文档、加粗、话题）。点击正文输入区后就地展开进入编辑模式（见 3.6，不弹窗）。发布框仅对会员、嘉宾、合伙人、星主显示；星友不显示发布框（星友不能发帖）。

**(2) 分类页签（顶部菜单）**

发布框下方为一排分类页签，页签就是星球的内容菜单，由后台配置驱动：

a. **最新**：固定为第一个页签、不可配置，展示全部帖子（官方内容 + 会员/嘉宾发帖 + 提问帖）按发布时间倒序。

b. **其余页签**：从后台资讯管理「菜单设置」配置的**一级分类**动态读取（示例：交易追踪、市场资讯、理财资讯、话题研究）。点击某个页签，仅展示该一级分类下的帖子。

c. **同步规则**：后台新增或启用一级分类并保存后，C 端进入页面时拉取最新分类列表生效；分类停用后对应页签不再展示，该分类下已发的帖子仍保留在「最新」页签中。

d. 帖子与分类的归属关系见 3.6 标签字段：发帖时选择的标签挂在某个一级分类下，帖子随之归入对应页签，一个帖子可同时归属多个页签。

**(3) 置顶公告区**

分类页签下方为置顶公告区，单独一个卡片，展示后台资讯管理中标记为置顶的官方内容，每条一行：

a. 每条以绿色「置顶」标识开头，图文帖显示「图片」类型前缀，超长截断。

b. 公告中的链接文字使用主题蓝色，点击跳转对应页面或外部链接。

c. 置顶内容按后台设置的置顶顺序展示，不参与信息流的时间排序。

b. 正文：**帖子没有标题字段**，卡片直接展示正文。首行常为加粗样式（发帖人自行设置，看起来像标题），正文中可内嵌 #话题标签（蓝色，点击进入标签聚合页，见 3.8）。列表态最多展示 6 行，超出折叠显示「展开全部」；点击时先校验会员身份（见 c），通过后在当前卡片内展开全文，再次点击收起。

e. 链接：正文中粘贴的链接发布后以超链接样式展示——显示自动识别的链接标题文字，蓝色可点击，点击新窗口打开原网页；识别失败时展示裸链接。

f. 标签胶囊：正文下方以浅绿底胶囊展示该帖标签；正文内嵌 #话题与标签胶囊点击均进入标签聚合页（见 3.8）。

h. 点赞人列表：有点赞时在互动行下方展示点赞用户昵称（蓝色，最多展示 10 个），格式"昵称1、昵称2 … 等 N 人觉得很赞"；仅 1 人时显示"昵称 觉得很赞"；无人点赞不展示。

k. ● 异常交互说明：被后台下架/删除的帖子，信息流不再展示；若用户正停留在已展开的该帖详情弹窗，关闭后提示"该内容已被删除"。

- 文档：pdf/doc/docx/xls/xlsx/ppt/pptx/txt，单个不超过 50MB，最多 5 个；
- 上传后在编辑器底部展示已传文件列表，点击 × 可删除单个文件。

e. 标签（主题分类）：标签即后台资讯管理「菜单设置」中配置的**二级分类**（挂在某个一级分类下）。点击工具栏【#】打开标签选择面板（见原型示意二）：面板按**一级分类**分组（绿色竖条 + 分组名），组内展示该分类下的标签胶囊；点击标签选中，最多 3 个，再次点击取消选择，选中的标签以蓝色胶囊回显在编辑器底部「已选标签」行；点击面板外任意位置收起面板。

f. **帖子归属规则**：保存时帖子归入所选标签各自的父级一级分类。例如选择标签「自由现金流」（属于一级分类「交易追踪」），帖子就出现在「交易追踪」页签下；所选标签跨分类时，帖子同时出现在多个页签；无论选了什么标签，帖子始终出现在「最新」页签。

g. 编辑自己的帖子时，编辑器处于编辑态：各字段带入原值（正文、附件、标签），可修改全部字段，也可删除已有附件。

h. 底部工具栏：表情按钮为二期预留（点击提示"即将上线"）；【图片】【文档】用于上传附件；【B】加粗选中的文字；【#】打开标签选择面板（见 e）。

**(3) 提交逻辑**

点击【发布】时校验正文必填，附件尚在上传中时提示"附件上传中，请稍候"。校验通过后帖子出现在信息流最顶部（置顶帖除外，官方置顶帖始终在最前），提示"主题动态发布成功"，编辑器收起还原为发布框。点击【收起】或页面空白处时：正文有内容则提示"放弃编辑？"防误触，确认后清空内容并收起。

**(2) 字段与逻辑说明**

f. ● 异常交互说明：被提问对象的角色后续被后台调整（如嘉宾移出嘉宾组），已生成的提问帖不受影响，正常展示；但该用户不再出现在可提问名单中。

## 4. 后台管理端（本期涉及部分）

后台沿用芋道管理端的标准样式（斑马纹表格、标签状态、右对齐操作按钮）。本章只写本期需要新增或调整的功能，已有的基础能力不重复展开。

### 4.1 会员商品配置

在「商城 → 商品管理」新建虚拟商品「年度会员」：

- 商品类型：虚拟商品，无需物流。
- 价格：¥599，划线价 ¥999（价格后续可随时在后台调整，C 端开通弹窗跟随商品价格展示）。

### 4.3 会员管理

沿用现有「会员管理 → 会员会员列表」（member/user）页面，本期补充：

a. 列表增加「分组/角色」列与「会员到期时间」列，支持按分组筛选（如只看会员）。

b. 详情/编辑中可调整用户所属分组，调整后用户角色即时变化（2.2）。

c. 手动把用户加入会员组时，需要同时填写到期时间（适用于赠送、线下收款补录的场景）。

d. 会员标签与会员详情「备注」字段为已有能力，直接复用：C 端成员卡片（3.9）的「标签」行读取会员标签、「简介」行读取备注，管理方在会员详情中维护即可，无需新建页面。

### 4.4 资讯管理（本次新建）

后台「资讯管理」模块（页面路径 cms/workspace）为本次全新开发，无既有页面可沿用。它统一管理官方内容与 C 端 UGC（会员发帖、提问帖），并承担 C 端信息流的菜单（一级分类）与标签（二级分类）配置。页面采用后台标准样式：斑马纹表格、标签状态、操作按钮右对齐。

**本模块不提供内容发布入口**：官方内容与 UGC 一律通过 C 端发布（官方账号在 C 端发帖），发布后自动进入本列表，后台仅做治理（置顶/上下架/删除，评论在详情弹窗内删除）与配置。

**(1) 内容列表**

**原型示意（搜索工作栏 + 列表）**：

```
+------------------------------------------------------------------------------------------+
| 关键词 [标题/正文/作者昵称]  状态[全部v] 菜单[全部v] 置顶[全部v] 发布时间[起~止]            |
|                                          [搜索] [重置]              [⚙ 菜单设置]          |
+------------------------------------------------------------------------------------------+
| 作者      角色   内容(≤2行)              菜单     标签    赞 评 分 置顶 状态   发布时间        操作    |
|---------------------------------------------------------------------------------------------------|
| [头像]Mark  [会员] 美国消费大超预期，经济韧性…  市场资讯  市场资讯 31 12 3  是  [已上架] 2026-09-17 16:42 详情 更多v |
| [头像]老张  [星主] 组合月报解读：红利低波策略…  理财资讯  红利低波  8  2 1  -  [已上架] 2026-09-16 10:20 详情 更多v |
| [头像]李四  [会员] 向老林提问：下半年债券配置… 综合讨论   -       5  4 0  -  [已下架] 2026-09-15 18:03 详情 更多v |
|---------------------------------------------------------------------------------------------------|
|                                         « 1 2 3 »  10 条/页                                       |
+------------------------------------------------------------------------------------------+
```

a. 搜索工作栏：关键词（匹配标题/正文/作者昵称）、状态（已发布/已下架）、菜单（按一级分类筛选，含「综合讨论」）、置顶（已置顶/未置顶）、发布时间区间；【搜索】【重置】执行查询；【菜单设置】打开菜单设置弹窗（见 (3)）。

b. 列表列（列头与内容均左对齐）：作者（头像 + 昵称）、角色（星主/合伙人/嘉宾/会员/星友徽章标签）、内容（纯文本，不区分标题/描述，最多 2 行超出省略，点击打开详情弹窗）、菜单（帖子归属的一级分类名；未匹配任何菜单的显示「综合讨论」，仅管理端概念，C 端无此页签）、标签（帖子选中的二级分类标签）、点赞/评论/分享（三项计数）、置顶（是 / -）、状态（已上架/已下架标签，位于「置顶」与「发布时间」之间）、发布时间（具体时间点，如 2026-09-17 16:42）、操作（右对齐：详情 + 更多下拉）。

c. 排序与分页：置顶内容优先展示，其余按发布时间倒序；每页 10 条，底部分页控件。

d. 操作：

- **详情**：打开内容详情弹窗（见 (2)）。
- **更多下拉**：下架/上架（按当前状态互切）、置顶/取消置顶（仅已上架内容可置顶）、删除。
- **下架**：状态改为已下架并自动取消置顶，C 端信息流立即不再展示该帖；若用户停留在该帖详情弹窗，关闭后提示"该内容已被删除"。
- **上架**：重新进入 C 端信息流，按发布时间参与排序。
- **删除**：二次确认"是否确认删除内容「XX」？删除后不可恢复"，确认后从列表移除，C 端同步消失。

e. 边界说明：本页不做批量操作（无复选框、无批量下架/批量删除）；无「精华」「收进专栏」操作。

a. 弹窗顶部固定说明文案："菜单展示在客户端资讯页顶部菜单栏；标签以话题形式展示在内容标题前和底部。"

b. 结构为菜单（一级）→ 标签（二级）：

- 每个菜单一个块：菜单名称可直接编辑（输入框），右侧显示「N 个标签」统计与【删除】按钮；
- 删除菜单：二次确认"删除菜单「X」及其下 N 个标签？"，确认后该菜单与其下标签一并从草稿移除；
- 标签以胶囊展示，点 × 即从草稿移除；下方输入框输入标签名 +【添加标签】追加，同名标签提示"该标签已存在"，空名称提示"请输入标签名称"；
- 弹窗底部为【添加菜单】区：输入菜单名 +【添加菜单】，同名菜单提示"菜单已存在"，空名称提示"请输入菜单名称"。

c. 草稿与保存：弹窗内所有增删改仅作用于草稿，点底部【保存】后统一生效并提示"菜单设置已保存"；点【取消】或关闭弹窗即丢弃未保存的修改。

d. C 端联动：

- **一级菜单** → C 端信息流顶部页签（「最新」固定第一个，不来自配置，见 3.5）；
- **二级标签** → C 端发帖标签选择面板（按一级菜单分组展示，见 3.6）；
- 保存后 C 端下次进入页面时拉取最新配置生效；删除菜单/标签不影响已发的帖子，帖子仍保留在「最新」页签，对应页签/标签选项不再出现。

e. 帖子归属（与 3.6 帖子归属规则一致）：发帖时选择的标签决定帖子归属的页签——标签挂在哪个菜单下，帖子就出现在哪个页签；所选标签跨菜单时帖子同时出现在多个页签；无论选了什么标签，帖子始终出现在「最新」页签；未匹配任何菜单的帖子仅出现在「最新」，管理端列表菜单列显示「综合讨论」。

### 4.5 退款处理与自动降级

- 会员商品订单发生退款（后台审核或售后流程）成功后，系统自动将该用户移出会员组、加入星友组（见 2.4），无需人工处理。
- 会员到期降级由每日定时任务完成，任务执行结果建议在后台有日志可查（处理了多少人、哪些人），方便排查。

## 5. 非功能性需求

- **权限校验**：帖子详情接口必须在服务端校验会员身份（非会员请求直接拦截并返回特定状态码，前端据此弹出开通会员弹窗），列表接口不做限制；帖子的编辑/删除接口校验"仅作者本人"。
- **性能**：信息流分页加载（每页 20 条），首屏 2 秒内可见；成员列表懒加载。
- **合规**：注册需勾选《服务协议》《隐私政策》；短信验证码有频控（同手机号 60 秒 1 条、每天上限 10 条）；支付走微信支付正式商户。
