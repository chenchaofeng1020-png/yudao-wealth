## 1. 概述

### 1.1 背景

运营需要定期组织线下活动（投资沙龙、行业分享会等）邀请客户到场参加，客户报名需要登记个人信息并支付报名费。当前系统不具备线下活动能力，活动组织依赖群内接龙与人工登记，报名信息分散、费用收取不规范、名单汇总靠手工。

本文档规划「线下活动」模块的完整链路：管理后台创建与管理活动，C 端活动页承接客户报名与支付，报名数据回流后台供查看与导出。

### 1.2 目标

- 运营可以在后台完成活动的全生命周期管理：新建 → 发布 → 报名 → 下架 → 删除。
- 活动报名费通过商城虚拟商品承接，客户支付走商城订单与支付能力，报名记录与订单一一对应。
- 客户在微信内打开活动页，使用财富星球账号密码登录（不使用微信授权登录），填写报名人信息并通过短信验证码校验后完成下单支付。
- 报名名单实时落库，运营可在后台按活动查看与导出。

### 1.3 功能模块范围

| 端 | 模块 | 功能板块 | 功能点描述 |
|---|---|---|---|
| 管理后台 | 活动管理 | 活动列表 | 标准表格、状态筛选、关键词搜索 |
| 管理后台 | 活动管理 | 新建/编辑活动 | 基本信息（含封面）、报名费与商品绑定、名额与限购、报名截止、活动详情 |
| 管理后台 | 活动管理 | 状态流转 | 未发布 / 报名中 / 已结束 / 已下架 |
| 管理后台 | 活动管理 | 分享 | 活动链接复制、二维码下载 |
| 管理后台 | 活动管理 | 活动详情页 | 活动信息卡片、报名名单页签查看、汇总统计、导出 Excel |
| C 端 | 活动报名 | 活动介绍页 | 活动信息与详情展示、报名入口 |
| C 端 | 活动报名 | 报名流程 | 账号密码登录、报名人信息填写（短信验证码）、订单确认与支付 |
| C 端 | 活动报名 | 报名结果 | 报名成功展示、名额与截止状态控制 |

### 1.4 名词和缩略语

| 术语 | 说明 |
|---|---|
| 活动 | 一场线下活动的完整信息：基本信息、活动详情、报名费、名额、报名截止时间 |
| 报名人 | 一张票对应的到场人，一个报名人包含真实姓名、手机号、理财师姓名三项信息 |
| 报名费 | 客户报名需支付的费用，由活动绑定的商城虚拟商品价格承接 |
| 有效报名 | 支付成功且未退款的报名人记录，占用活动名额 |
| 每账号限购 | 同一账号在该活动下累计可购买的最大票数（含多次购买） |

## 3. 管理后台：活动管理

入口：管理后台「营销中心 > 活动管理」。页面采用后台标准表格风格（斑马纹、状态标签、操作列右侧固定）。

### 3.1 活动列表

**原型示意**：

```
+------------------------------------------------------------------------------+
| 营销中心 · 活动管理                                          [+ 新建活动]     |
|------------------------------------------------------------------------------|
| 状态[全部 ▾]   关键词[搜索活动名称______]                        [重置筛选]    |
|------------------------------------------------------------------------------+
| 活动名称           | 报名费 | 名额进度  | 状态   | 活动时间      | 操作         |
|--------------------|--------|-----------|--------|---------------|--------------|
| 十月投资沙龙·上海站 | ¥299   | 42/80     | 报名中 | 10-28 14:00   | 详情 分享    |
|                    |        |           |        | ~ 10-28 17:00 | 编辑 下架    |
| 九月行业分享会      | ¥199   | 30/30 已满员 | 报名中 | 09-20 14:00 | 详情 分享    |
|                    |        |           |        | ~ 09-20 17:00 | 编辑 下架    |
| （斑马纹交替行，操作右对齐）                                                   |
|------------------------------------------------------------------------------|
|                                                    < 1 2 3 ... >  每页 20 条  |
+------------------------------------------------------------------------------+
```

- 列表按创建时间倒序排列，每页默认 20 条；只要列表有数据就显示分页器，仅空列表隐藏。
- 每行展示：活动名称、报名费、名额进度（有效报名数/总名额）、状态标签、活动时间（开始~结束）、操作按钮。
- 名额进度以有效报名数为准（已取消的不计入）；满员时名额进度旁显示「已满员」标识。
- 状态标签配色：未发布（灰）、报名中（绿）、已结束（橙）、已下架（红）。
- 筛选区：状态下拉（全部 / 未发布 / 报名中 / 已结束 / 已下架，默认「全部」）+ 关键词搜索（按活动名称模糊匹配）。
- 操作按钮按状态展示，见 3.4 状态流转表。
- 删除需二次确认：「删除后活动不可恢复，确认删除？」；已产生报名记录（含已取消）的活动不允许删除，操作列不显示删除按钮，只能下架。

### 3.2 新建 / 编辑活动

点击「+ 新建活动」或列表中的「编辑」打开弹窗，弹窗设置最大高度并支持内部滚动。

**原型示意**：

```
+------------------------------------------------------------+
|  新建活动                                            [×]   |
|------------------------------------------------------------|
|  * 活动名称                                                |
|  [__________________________________________]              |
|                                                            |
|  * 活动封面                                                |
|  [+ 上传封面图]   建议尺寸 750×480，支持 jpg/png            |
|                                                            |
|  * 活动开始时间              * 活动结束时间                  |
|  [2026-10-28 14:00____]     [2026-10-28 17:00____]         |
|                                                            |
|  * 活动地点                                                |
|  [上海市浦东新区××路××中心 3F______]                        |
|                                                            |
|  * 报名费(元)        * 总名额(人)      * 每账号限购(张)      |
|  [299____]           [80____]          [2_____]            |
|  (系统自动创建绑定虚拟商品)                                  |
|                                                            |
|  * 报名截止时间                                            |
|  [2026-10-27 18:00____]                                    |
|                                                            |
|  * 活动详情 (富文本)                                       |
|  +------------------------------------------------+       |
|  | 一、活动议程……                                  |       |
|  | [图片]                                          |       |
|  +------------------------------------------------+       |
|                                                            |
|              [ 存草稿 ]         [ 保存并发布 ]              |
+------------------------------------------------------------+
```

**(1) 字段说明**

a. 活动名称：必填，文本，最多 50 字。

b. 活动封面：必填，单图上传；建议尺寸 750×480，支持 jpg/png；展示于 C 端介绍页顶部与后台活动详情页信息卡片。

c. 活动开始/结束时间：必填，精确到分；结束时间必须晚于开始时间。

d. 活动地点：必填，文本，最多 100 字，展示于 C 端介绍页。

e. 报名费：必填，大于 0 的金额。保存发布时系统自动创建一个与该活动绑定的商城虚拟商品，商品价格即报名费，客户报名支付通过该商品下单（与直播录播上架绑定虚拟商品的既有链路一致）。一个活动只绑定一个商品，绑定关系创建后不可更换。

f. 总名额：必填，大于 0 的整数，单位为「人」（一票一人）。

g. 每账号限购：必填，大于 0 的整数，单位为「张」，默认 1；同一账号在该活动累计有效票数不可超过该值。

h. 报名截止时间：必填，必须早于活动结束时间；截止后 C 端自动关闭报名入口。

i. 活动详情：必填，富文本编辑器，支持图文混排与图片上传（与直播 AI 会议纪要编辑器一致），展示于 C 端介绍页。

**(2) 保存逻辑**

- 「存草稿」：校验必填项后保存为「未发布」，C 端不可访问，不生成分享链接。
- 「保存并发布」：校验全部必填项，创建绑定虚拟商品，状态进入「报名中」，生成分享链接与二维码。
- 编辑「报名中」活动：活动名称、时间、地点、活动详情、报名截止时间、总名额、每账号限购可修改；总名额不可低于当前有效报名人数，每账号限购不可低于当前任一账号已购张数；报名费不可修改（如需调价先下架，下架后修改报名费会生成新的绑定商品，原订单不受影响）。
- 编辑「未发布」「已下架」活动：全部字段可修改。
- 编辑「已结束」活动：仅活动详情可修改。

### 3.3 分享链接与二维码

- 入口：列表操作列「分享」，打开分享弹窗。
- 弹窗展示活动分享链接（文本 + 复制按钮）与活动二维码（下载按钮），二维码内容即分享链接。
- 仅「报名中」状态提供分享入口；未发布活动无链接可分享。
- 客户通过链接或扫码打开 C 端活动介绍页；「已下架」「未发布」状态的链接打开提示「活动不存在或已结束」。

**原型示意**：

```

|----------------------------------------------|
|  活动链接                                    |
|  [https://…/activity?id=123______] [复制]    |
|                                              |
|  活动二维码                                  |
|        +------------------+                 |
|        |  ▓▓▓▓▓▓  ▓▓▓▓    |                 |
|        |  ▓▓▓  ▓▓▓▓▓▓▓    |                 |
|        |  ▓▓▓▓▓▓▓  ▓▓▓    |                 |
|        +------------------+                 |
|                                              |
|              [ 下载二维码 ]                  |
+----------------------------------------------+
```

### 3.4 状态流转

```
【未发布】──保存并发布──►【报名中】──报名截止时间到──►【已结束】
    ▲                      │    ▲                    │
    │                      │    └──重新上架(未过截止)─┘
    └─────────编辑─────────┘
                           │ 手动下架
                           ▼
                       【已下架】
```

| 状态 | 进入方式 | C 端可见性 | 允许的操作 |
|---|---|---|---|
| 未发布 | 存草稿 | 链接不可访问 | 编辑、发布、删除（二次确认） |
| 报名中 | 保存并发布 / 重新上架 | 介绍页可访问、可报名 | 详情、分享、编辑、下架 |
| 已结束 | 报名截止时间自动流转 | 介绍页可访问、报名入口关闭 | 详情、编辑（仅详情） |
| 已下架 | 列表「下架」 | 链接不可访问 | 详情、编辑、上架（未过截止时间才可重新上架）、删除（无报名记录时） |

- 已结束为系统自动流转，无需人工操作。
- 下架不删除数据；报名名单、订单与退款状态全部保留。
- 活动开始时间到达后状态保持「已结束」，C 端介绍页仍可访问，仅展示活动信息。

### 3.5 活动详情页

- 入口：列表操作列「详情」，所有状态均可进入，在当前页面内切换展示（返回列表回到列表视图）。
- 页面顶部为活动信息卡片：左侧封面图，右侧活动名称、状态标签、活动时间、活动地点、报名费、名额进度（满员显示「已满员」）；卡片右上角提供「编辑」「分享」按钮，操作规则与列表一致（分享仅报名中可用）。
- 卡片下方为报名名单区，按页签查看（页签带实时计数）：全部（N） / 已报名（N） / 已取消（N）。
- 名单以「报名人」为行单位：一个报名人一条记录，同一订单购买多张票时拆分为多条记录（订单号相同）。
- 每条记录展示：真实姓名、手机号、理财师姓名、报名时间（支付时间）、支付金额、报名状态、订单号。
- 报名状态：已报名（绿点）、已取消（灰点，对应退款成功）。
- 「导出 Excel」按钮：导出当前页签结果，字段与名单一致；导出文件命名「活动名称-报名名单-导出日期」。

|------------------------------------------------------------------|
|  姓名  | 手机号      | 理财师 | 报名时间        | 价格 | 状态    |
|--------|-------------|--------|-----------------|------|---------|
| 张三   | 138****1234 | 李四   | 10-13 17:41:03  | ¥299 | ●已报名 |
| 王五   | 139****5678 | 赵六   | 10-12 09:26:37  | ¥299 | ○已取消 |

## 4. C 端：活动介绍页与报名

### 4.1 活动介绍页

- 客户通过分享链接或扫码在微信内打开，为独立落地页布局（不含星球三栏结构与导航），无需登录即可浏览。
- 页面展示：活动封面（顶部通栏）、活动名称、活动时间、活动地点、报名费、名额进度（剩余名额/总名额）、报名截止时间、活动详情（富文本）。
- 底部固定报名操作栏，按钮文案与可用性按状态展示：

| 活动状态 | 报名按钮 |

| 报名中且有余量 | 「立即报名」，可点击 |
| 报名中但已满员 | 「已满员」，置灰不可点击 |
| 已结束（截止或手动） | 「报名已结束」，置灰不可点击 |

### 4.2 登录

- 点击「立即报名」时校验登录态：未登录弹出登录弹窗，使用财富星球账号密码登录（手机号+密码，与 C 端现有登录一致），不使用微信授权。
- 未注册客户可在登录弹窗内切换到注册页，注册成功后继续报名流程，登录前后停留在当前活动页不跳转。

### 4.3 填写报名人信息

- 登录后进入报名信息填写页：默认展示 1 个报名人表单，可通过「添加报名人」追加，上限为「每账号限购张数 - 该账号累计有效票数」与「活动剩余名额」中的较小值。
- 每个报名人填写：
  - 真实姓名：必填，文本，最多 20 字。
  - 手机号：必填，11 位手机号，每个报名人的手机号均需短信验证码校验（点击「获取验证码」，60 秒内不可重发）；验证码错误在输入框下方红色提示。
  - 理财师姓名：必填，文本，最多 20 字。
- 同一活动同一手机号的报名人重复时，提交时提示「该手机号已报名本活动」。

**原型示意**：

```
+----------------------------+
|  填写报名人信息             |
|  报名人 1                   |
|  * 真实姓名 [________]     |
|  * 手机号   [________]     |
|              [获取验证码]   |
|  * 验证码   [____]         |
|  * 理财师姓名 [________]   |
|                            |
|  + 添加报名人 (限购 2 张)   |
|                            |
|  合计：1 张 · ¥299         |
|----------------------------|
|      [  提交并支付  ]      |
+----------------------------+
```

### 4.4 订单确认与支付

- 报名人信息校验通过后进入订单确认页，购买数量与报名人数量一致且不可修改。
- 订单确认页展示：活动门票商品（活动名称作为商品名）、单价（报名费）、购买数量（票数）、合计金额；点击「提交订单」后唤起微信支付。
- 提交订单时报名人信息随订单提交暂存；支付成功后系统生成报名记录（每个报名人一条），状态为「已报名」，同步占用名额并更新后台名单。
- 支付取消或超时未支付：报名不生效、不占用名额、不生成报名记录；客户可从活动介绍页重新发起报名。

### 4.5 报名结果

- 支付成功后页面展示报名成功提示，并显示活动时间、地点与票数，提示客户届时到场。
- 已报名客户再次打开活动介绍页并点击「立即报名」时，页面提示当前账号在本活动的累计有效票数与剩余可购张数；达到限购或满员后报名按钮置灰为「已报名满额」并展示已购票数。

### 4.6 退款

- 退款复用商城订单退款能力，运营在商城订单管理中发起，活动模块不提供独立退款入口。
- 退款成功后，该订单对应的所有报名人记录自动变更为「已取消」，名额同步释放，活动名额进度与 C 端剩余名额实时更新。
- 已取消的报名人不再计入有效报名与实收金额汇总。

## 5. 名额与限购规则

- 名额按「人」计：一张票对应一个报名人，购买 N 张票占用 N 个名额。
- 有效报名 = 支付成功且未退款的报名人记录；有效报名数达到总名额即满员，报名入口关闭。
- 每账号限购按累计有效票数计算（含多次购买）：账号累计有效票数 + 本单购票数 ≤ 每账号限购张数。
- 报名资格双重校验：报名截止时间与剩余名额，任一不满足即关闭报名入口。
- 并发边界：最后一组名额被多人同时下单支付时，以支付成功顺序为准；支付成功时名额已满的订单自动全额退款，对应报名不生效。
