## 1. 概述

### 1.1 背景
财富星球（财不外露社群）的 PC 端已完成资讯信息流、专栏深度长文、会员体系与个人中心的策划与原型验证。投资社群用户具有极强的碎片化、移动化使用习惯（如早盘前刷资讯、通勤途中读研报长文、盘中关注交易追踪等），单纯依托 PC 端无法满足高频移动场景。

为此，我们启动移动端研发。第一阶段核心目标是做移动端适配，必须沿用 **UniApp（Vue 3 + Vite）** 框架进行开发，实现一套代码编译为 H5 与 iOS/Android 原生 App。

本期为移动端的第一版本（V1.0），功能必须**与 PC 端现有功能和业务规则严格保持一致**，不额外发明复杂新链路，重心在于**针对手机窄屏、单手触控与上下滑动操作习惯，进行最佳的移动端信息架构与排版重构**。

### 1.2 目标
1. **核心场景覆盖**：第一版本聚焦三大核心页面——【资讯】、【专栏】、【我的】，打通内容消费、深度长文研读、互动问答与会员变现完整闭环。
2. **双端规则对齐**：复用 PC 端已定稿的五大角色体系（星主、合伙人、嘉宾、会员、星友）、会员试读拦截（星友试读开头、会员看全文）、发帖与提问权限、点赞与评论互动规则。
3. **移动原生体验**：告别 PC 宽屏三栏模式，采用“底部 TabBar + 顶部吸顶页签 + 沉浸式阅读器 + 底部抽屉/浮层”的移动端黄金设计语言，适配 iOS/Android 刘海屏与底部操作条安全区。
4. **支持 App 打包**：工程遵循标准 UniApp 规范组织，满足 H5 预览、微信小程序以及 iOS/Android 离线打包/云打包 App 规范。

## 2. 移动端展示与交互架构设计

### 2.1 从 PC 宽屏到手机窄屏的转换哲学
PC 端屏幕空间充裕，通常采用“三栏式”（左侧导航 + 中间动态流 + 右侧资讯工具栏），专栏采用“左目录树 + 右长文”。但在手机移动端：
1. **必须砍掉多列并排**：单手握持状态下，屏幕宽度通常为 375px~430px，手机用户习惯自上而下的流式单列纵向阅读。
2. **专栏拆分为“合集索引页”与“沉浸阅读页”**：如果在单屏既塞目录树又塞正文，会导致排版局促、误触严重。因此，专栏入口展示专栏合集与章节列表；点击任意章节后，以平滑转场推入独立的“沉浸长文阅读页”；在长文页内，随时可通过右上方或底部的“目录抽屉”浮层随心切篇，兼顾大纲全局感与沉浸阅读舒适度。
3. **操作按键下沉**：PC 端的各类操作按钮在屏幕上方或侧边，而手机端单手操作黄金区在屏幕底部 1/3。因此，核心导航（TabBar）、文章翻篇（上一篇/下一篇）、互动（点赞/评论/分享）全部下沉到底栏，悬浮发帖按钮置于右下角拇指易触达区域。

### 2.2 底部导航栏（TabBar）结构
移动端底部常驻 3 个核心 Tab，高度 50px（加上 safe-area-inset-bottom 边距）：
- **资讯**：图标为动态/信息流图标，点击回到资讯流顶部，再次点击触发刷新。
- **专栏**：图标为书架/文集图标，展示所有分类下的精选专栏及章节索引。
- **我的**：图标为个人中心图标，展示个人档案、会员权益与账号设置。

## 3. 核心页面功能需求与原型

### 3.1 核心页面一：【资讯】（Feed）

#### 3.1.1 业务流程
用户打开 App，默认进入【资讯】Tab：
1. 顶部展示星球标题「财富星球」及当前用户身份微标（支持一键切换视角用于体验演示），右侧为全站搜索按钮。
2. 吸顶展示分类标签栏：用户横向滑动切换分类（最新、交易追踪、市场资讯、理财资讯、话题研究），流式列表平滑联动更新。
3. 置顶公告区紧跟其下，以轻量化卡片列出 1~3 条官方核心通知或直播预告，点击直接打开对应帖子详情。
4. 帖子信息流列表支持下拉刷新、上拉加载。
5. 右下角常驻悬浮发帖按钮（FAB）：
   - 会员及以上身份点击：弹出选项菜单（发布动态 / 向星主提问），进入编辑界面。
   - 星友身份点击：给出友好提示并弹出会员开通弹窗。

#### 3.1.3 字段与交互说明
1. **作者与身份行**：
   - 头像：点击跳转作者个人主页。
   - 昵称与角色徽章：星主（红底金字）、合伙人（蓝底）、嘉宾（紫底）、VIP会员（金底黑字）、星友（灰底）。
   - 右上角更多操作（`...`）：本人帖子可弹出【编辑】、【删除】；他人帖子可【复制链接】、【举报】。
2. **提问标识**：如果该帖属于提问帖，在作者下方以浅橙色卡片高亮显示“向 [被提问人] 提问：”。
3. **正文与折叠机制**：超过 5 行文本默认截断并显示【展开全部 ▾】，点击就地平滑展开为【收起全部 ▴】。
4. **附件与图片**：
   - 图片支持 1~9 张宫格排列，单张图片自适应大图，点击调起全屏图片预览器（支持手势缩放）。
   - 文档附件展示对应文件类型图标（PDF、Word、Excel 等）、文件名、大小及下载按钮。
5. **点赞与评论互动**：
   - 点赞：所有角色均可点击点赞，带轻快微动效，点赞数实时 +1 / -1。
   - 评论：点击气泡图标，会员及以上弹出底部快速回复输入框；星友点击则拦截提示“开通会员后即可参与讨论”，并唤起 VIP 开通弹窗。
   - “查看详情”：点击帖子空白区或右下角查看详情，平滑推入帖子独立详情页。

### 3.3 核心页面二：【专栏】（Columns）

#### 3.3.1 移动端展示策略
专栏是财富星球最重要的“知识资产与付费变现抓手”。PC 端采用左右两栏排版，而在移动端：
1. **专栏首页作为“专栏合集与目录索引”**：
   - 顶部提供专栏长文搜索框（快速搜索文章标题）。
   - 采用精致的专栏卡片列表，每个专栏展示封面大图、专栏名称、副标题、主理人、篇数与更新状态。
   - 默认展开当前热门专栏的章节列表，支持折叠/展开其他专栏。
   - 章节列表清晰标示状态：**绿色圆点**（当前阅读/正在读）、**蓝色圆点**（新上架未读）、**灰色圆点**（已读完成）、**免费试读/会员专享**微标。
2. **点击章节进入“沉浸长文阅读器”**：
   - 独立全屏阅读环境，字体与间距针对移动端手持阅读优化。
   - 顶部常驻【章节目录】按钮，随时可以从屏幕右侧滑出半屏目录抽屉，随意切换章节，无需退出阅读页。
   - 底部固定【上一篇】/【下一篇】切换与【点赞】、【收藏】、【分享】操作。
3. **试读截断与付费墙转化**：
   - 星友（未付费用户）阅读至约 300~500 字时内容自然截断，正文下方出现高斯模糊与向下渐隐遮罩。
   - 遮罩正下方紧接黑金尊贵风格的【会员专享付费卡片】（文案明确说明：“本专栏为深度投资研报，开通会员立即解锁全部章节与后续更新”），附带金黄色高光【立即开通会员（¥599/年）】按钮，点击就地拉起支付抽屉，转化路径极致顺畅。

## 4. UniApp 技术架构与 App 打包工程规范

### 4.1 技术选型与规范
- **开发语言与架构**：Vue 3.5+ (`<script setup lang="ts">`) + Vite 5 + UniApp 3.0。
- **状态管理**：Pinia（与 PC 端全局 store 逻辑完全一致，实现登录态、权限、视角切换以及实时点赞数据双向同步）。
- **样式方案**：原生 SCSS，采用移动端响应式尺寸与 Flex 弹性盒布局。
- **跨端兼容**：
  - H5 移动端 Web：自适应手机端居中限宽（最大 480px 居中），PC 打开自动居中呈现手机模拟比例。
  - 原生 App（iOS / Android）：顶部适配系统状态栏（`status-bar-height`），底部适配 iPhone Home 键触控条（`constant(safe-area-inset-bottom)` / `env(safe-area-inset-bottom)`）。

### 4.2 App 打包规范（manifest.json）
1. **基础配置**：
   - AppID: `__UNI__WEALTH_PLANET`
   - 应用名称: `财富星球`
   - 版本名称: `1.0.0`
   - 版本号: `100`
2. **App 权限最小化原则**：
   - 仅申请网络访问权限（`INTERNET`、`ACCESS_NETWORK_STATE`）及相册/存储权限（用于上传动态附件与更换个人头像）。
3. **状态栏与导航栏**：
   - 沉浸式透明状态栏（`titleNView: false` 或原生自定义导航栏）。
