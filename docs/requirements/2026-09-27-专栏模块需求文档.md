## 1. 概述

### 1.1 背景

财富星球是一个围绕投资与财富管理的付费社群：星友注册后可免费浏览资讯流，开通会员后解锁更完整的浏览与互动权益。

随着社区内容越积越多，两个问题逐渐凸显：

- 内容层面：资讯流以动态短内容为主，星主和嘉宾的系统性观点——行业分析、方法论、投资复盘——缺少合适的承载形式，散落在信息流里难以沉淀，也难以按主题连续阅读。
- 会员层面：星友能免费获得的内容和会员的差别不够直观，「开通会员能多得到什么」缺少一个具体、可感知的答案，会员转化缺少抓手。

为此规划「专栏」模块：专栏是一组分好组的深度长文，形态类似微信公众号文章，以文字+图片排版呈现，一篇讲透一个主题，多篇文章按顺序连载在同一专栏下。星主、合伙人等在管理后台持续连载更新；星友在客户端 PC 可免费试读每篇长文的开头部分，读完整篇需要开通会员，让深度内容成为会员权益最直观的体现；会员及以上角色免费阅读全文，并获得点赞、评论、分享等完整互动能力。

配套地，管理后台提供与 C 端对齐的管理能力：运营在后台「专栏」菜单维护专栏和长文，负责新建、编辑、上架、下架、删除，查看阅读数据，以及在文章详情中删除违规评论，保障内容质量与评论区合规。

本文档描述专栏模块的完整需求，分两大板块：第 3 章客户端 PC 专栏阅读，第 4、5 章管理后台专栏与长文管理。

### 1.2 目标

- 沉淀深度内容：为星主等创作者提供成体系的长文连载载体，与资讯流的动态短内容互补，让优质内容可沉淀、可连续阅读。
- 支撑会员转化：通过「试读 + 会员解锁全文」的权益设计，让星友在阅读中直观感知会员价值，为会员开通提供具体抓手；同时保证会员及以上角色的完整阅读与互动体验。
- 提升运营效率：为运营提供专栏与长文的全流程管理能力——编写、上架、下架、数据查看、评论治理，保障 C 端内容质量与评论区合规。
- 明确规则口径：统一阅读权限、试读规则、已读标记等核心规则的口径，以及管理后台操作与 C 端展示的联动关系。

## 2. 整体规则与双端联动

### 2.1 角色与阅读权限

- 星友（含游客视角）：每篇长文仅可阅读正文开头部分（试读规则见 3.5.1），正文底部展示付费卡片引导开通会员；不能点赞、不能评论、不能分享，点击对应入口时统一弹出开通会员弹窗。
- 会员及以上（会员、合伙人、嘉宾、星主）：免费阅读全部正文，可点赞、评论、分享，不出现付费卡片。
- 已读标记与权限联动：只有当前身份能解锁全文时，点开文章才计为已读；星友/游客看到的是截断内容，不计已读（详见 3.3.3）。

### 2.2 长文状态流转

长文围绕「草稿 → 已上架 → 已下架」三个状态流转，评论治理贯穿已上架阶段：

```
  新建/编辑长文（编辑器页）
      │
      ├─ 存草稿 ──► 【草稿】──「保存并上架」/列表「上架」──► 【已上架】──列表「下架」──► 【已下架】
      │                                                        ▲                          │
      │                                                        └───────列表「上架」─────────┘
      └─ 删除（三种状态均可删，均需二次确认，不可恢复）
```

- 草稿：仅后台可见，C 端不展示。存草稿时标题、所属专栏为必填，主笔作者与正文可暂缺。
- 已上架：C 端专栏内展示、可阅读。编辑保存后实时同步 C 端，无需重新上架。
- 已下架：C 端不可见。阅读、点赞、评论数据保留，重新上架后恢复展示。
- 首次上架记录发布时间，后续编辑保存不改变发布时间。

### 2.3 双端联动

| 管理后台操作         | C 端表现                      |
| -------------- | -------------------------- |
| 新建专栏（默认已上架）    | 左侧目录出现该专栏；空专栏展开后显示「暂无收录长文」 |
| 专栏下架 / 上架      | 目录中该专栏及其全部长文消失 / 恢复，数据不变   |
| 长文上架 / 下架 / 删除 | 文章出现在 / 消失于目录与阅读页          |
| 拖动调整专栏顺序     | C 端左侧目录按相同顺序展示           |
| 编辑长文保存         | 已上架长文实时同步 C 端；存草稿仅后台可见     |
| 设置长文排序号        | C 端目录按排序号降序展示文章（越大越靠前）    |
| 长文转移专栏         | 原专栏与新专栏的文章数量同步增减           |
| 删除评论           | C 端同步移除该评论，评论计数减一          |

## 3. 客户端 PC：专栏阅读

### 3.1 页面布局总览

客户端 PC 整体为三栏结构：左侧品牌与导航栏、中间内容区、右侧信息栏。进入「专栏」后页面切换为独立布局：**右侧信息栏不显示**，专栏页占满内容区，内部为「左侧目录树 + 右侧文章阅读区」两栏结构。

**原型示意**：

```
+--------------------------------------------------------------------------+
| 左侧导航  │   左侧目录树              │         文章阅读区                  |
|----------+---------------------------+-----------------------------------|
| [财] 财不外露│  专栏    [搜索文章名称_] │                                   |
| (搜索框)  │  ▾ AI产业研究 (4)        │                                   |
|  资讯     │    ● 宏观大盘指标分析完结   │  [头像] Rich                      |
| ● 专栏    │    · 券商行情软件横评      │  2026-09-24 17:17          [⛶]   |
|  直播     │    · 美股概览(已读弱化)    │                                   |
|  课程     │  ▸ 港股观察 (6)          │  文章大标题                        |
|          │  ▸ 债券入门 (2)          │  正文……（富文本排版）               |
| [开通会员] │                         │                                      |
| [头像 用户]│                         │  [← 上一篇]  [下一篇 →]            |
|          │                         │  赞   讨论   分享                  |
|          │                         │  Rich、Mark 等 4人觉得很赞          |
|          │                         │  评论区（输入框默认收起）             |
+--------------------------------------------------------------------------+
```

### 3.2 专栏入口

- 左侧导航依次为：搜索框、资讯、专栏、直播、课程。点击「专栏」进入专栏页。
- 「专栏」为当前页时，导航项呈选中高亮态。
- 点击左侧导航顶部的品牌区（logo + 「财不外露」），返回资讯流。
- 从资讯流等其他页面进入专栏页时，默认展开第一个专栏并定位到其中一篇文章。

### 3.3 左侧专栏目录树

#### 3.3.1 专栏列表

- 目录树顶部为「专栏」标题和「搜索文章名称」输入框。
- 专栏以手风琴形式纵向排列：每行由三角箭头 + 专栏名称 + 文章数组成。点击行展开/收起该专栏；展开时三角朝下，收起时三角朝右。
- 专栏顺序与管理后台「专栏目录」的拖动排序一致（按后台排序号降序展示，见 4.2.1）。
- 文章按管理后台设置的排序号降序展示，序号越大越靠前（见 5.2）。
- 点击文章条目即打开该文章，阅读区回到顶部。

**原型示意**：

```
+------------------------------+
| 专栏         [搜索文章名称__] |
|------------------------------|
| ▾ AI产业研究 (4)             |
|   ● 宏观大盘指标分析完结       |   ← 当前阅读：圆点高亮，标题强调显示
|   · 券商行情软件横评          |   ← 未读：行首圆点标记
|   · 美股概览                  |   ← 已读：无圆点，标题弱化
| ▸ 港股观察 (6)               |   ← 收起状态，三角朝右
| ▸ 债券入门 (2)               |
+------------------------------+
```

#### 3.3.2 文章搜索

- 在搜索框输入关键词后，按文章标题模糊匹配，跨专栏过滤：只保留命中文章所在的专栏，且这些专栏自动展开。
- 无匹配结果时，目录区显示「未找到相关文章」。
- 清空关键词后恢复原目录顺序与展开状态。
- 专栏下没有文章时，展开后显示「暂无收录长文」。

#### 3.3.3 已读/未读标记

- 未读文章：行首显示实心圆点标记。
- 当前正在阅读的文章：行首高亮圆点、标题强调显示，与未读/已读状态互不干扰。
- 已读文章：圆点消失，标题弱化显示；鼠标悬浮或被选中时恢复正常显示。
- 已读判定规则：点开文章且**当前身份能解锁全文**时计为已读；星友/游客看到的是截断内容，不计已读。
- 已读标记不区分身份：同一浏览器内，任一能解锁全文的身份读过即标记，切换身份视角后已读状态共用。
- 已读记录保存在本机浏览器（localStorage），换设备或清除浏览器缓存后不同步。

### 3.4 文章阅读页

#### 3.4.1 作者行

- 文章标题上方展示作者信息：圆形头像 + 作者昵称，下一行显示发布时间（格式如 2026-09-24 17:17）；未选择主笔作者的文章不显示作者信息行，仅显示发布时间。
- 作者行右侧为沉浸模式开关按钮（见 3.4.2）。

#### 3.4.2 沉浸模式

- 点击作者行右侧的沉浸模式按钮进入：左侧目录树收起，阅读区独占整个专栏页，按钮变为激活态。
- 沉浸模式下阅读区干净无遮挡，顶部不再显示悬浮提示条或退出按钮。
- 进入/退出时均有 toast 提示。
- 退出方式：再次点击沉浸模式按钮、或按键盘 Esc 键。退出后目录树恢复。

**原型示意**：

```
+------------------------------------------------------+
|   [头像] Rich                                        |
|   2026-09-24 17:17                                   |
|   文章大标题                                          |
|   正文……（左侧目录已收起，阅读区占满）                   |
+------------------------------------------------------+
```

#### 3.4.3 正文渲染

正文按富文本排版展示，当前支持以下元素：

- 章节标题（一至四级）、加粗、斜体；
- 有序/无序列表（支持多级嵌套）；
- 引用块、行内代码、代码块、分割线；
- 表格、超链接（链接文字高亮色）、图片（宽度自适应正文宽度）。
- 系统不默认展示风险提示等声明文案；如有需要，作者可在正文末尾自行撰写。

### 3.5 付费墙与阅读权益

#### 3.5.1 试读截断规则

- 星友/游客打开长文时，统一按全文的 20% 直接截断，仅展示正文开头部分，不设短文豁免。
- 截断位置以上有渐隐遮罩过渡，提示下方还有内容。
- 会员及以上角色打开同一篇文章时全文直接可见，无遮罩与付费卡片。

#### 3.5.2 付费卡片

截断处下方展示付费卡片，点击按钮打开「开通会员」弹窗。

**原型示意**：

```
|   正文最后可见段落（渐隐淡出）……          |
|   +--------------------------------------+     |
|   |               (锁图标)                |     |
|   |      本文余下内容为会员专享             |     |
|   |  开通「年度星球会员」，畅读本专栏全部     |     |
|   |        连载与深度投研长文               |     |
|   |                                      |     |
|   |   [ 开通会员解锁全文 · ¥1,299 / 年 ]   |     |
|   +--------------------------------------+     |
```

- 卡片组成：锁图标、标题「本文余下内容为会员专享」、说明文案、主操作按钮「开通会员解锁全文 · ¥1,299 / 年」。
- 会员价格为固定展示文案（¥1,299/年），暂不在后台配置；后续如需运营调价，迁移至会员模块统一配置。

### 3.6 翻篇与互动

#### 3.6.1 上一篇/下一篇导航

正文下方为双列导航卡片，点击切换到对应文章。

**原型示意**：

```
+---------------------------+---------------------------+
| ← 上一篇                  | 下一篇 →                  |
| 宏观大盘的指标分析已经完结     | 券商行情软件横评：谁更强…    |
+---------------------------+---------------------------+
```

- 空态处理：当前已是第一篇时，左卡显示「第一篇 / 已是专栏起始篇章」；已是最后一篇时，右卡显示「最新篇 / 专栏已读至最新章节」。
- 切换文章后阅读区回到顶部。
- 上一篇/下一篇按目录顺序（排序号降序）计算。

#### 3.6.2 点赞

- 点赞仅限会员及以上：星友/游客点击点赞图标时不出点赞，统一弹出开通会员弹窗。
- 会员及以上点击点赞图标完成点赞，图标变为已点亮状态；再次点击取消点赞。
- 已有点赞时，操作栏下方显示一行点赞人文字，如：「Rich、Mark、John、Jerry 等 4人觉得很赞」，点赞人昵称高亮显示。
- 点赞数据与后台长文列表「点赞」列同源。

#### 3.6.3 评论

- 评论区对所有人可见；发表评论仅限会员及以上，星友/游客不展示评论输入框，点击「讨论」按钮时弹出开通会员弹窗。
- 会员及以上：评论输入框默认收起，点击操作栏「讨论」按钮展开输入框并自动聚焦（再次点击「讨论」收起）。
- 发表评论：输入内容后按回车或点击「发送」按钮；内容为空时发送按钮置灰。
- 每条评论展示：头像、昵称、评论时间、评论内容。
- 删除评论：鼠标悬浮自己发表的评论时，右侧出现删除图标，点击后二次确认「确认删除这条评论？」，确认后评论移除。
- 评论较多时列表默认收起为固定高度（约两条），底部显示「展开」按钮；展开后可「收起」。
- 无评论时显示「暂无讨论，发表你的第一条深度评论吧」。

**原型示意**：

```
| ------------------------------------------------------ |
|  （点击「讨论」后展开输入框）                               |
|  [___________________________________] [发送]           |
|                                                        |
|  [头像] Rich        2026-09-24 18:30                   |
```

#### 3.6.4 分享

- 分享仅限会员及以上：星友/游客点击「分享」图标时弹出开通会员弹窗，不复制链接。
- 会员及以上点击「分享」图标，复制当前文章的访问链接到剪贴板，并以 toast 提示「长文链接已成功复制到剪贴板」。
- 打开分享链接后定位到对应专栏与文章，按打开者身份展示对应阅读权限（星友/游客试读+付费卡片）。

## 4. 管理后台：专栏管理

### 4.1 页面布局总览

入口：管理后台「专栏」菜单（页面路径 /cms/content），该菜单仅对具备内容管理权限的运营角色可见。页面为「左侧专栏目录 + 右侧专栏工作区」两栏结构。

**原型示意**：

```
+------------------------------------------------------------------------------+
| 专栏目录 [+ 新建专栏]   │  「AI产业研究」 [已上架]        [写文章] [编辑] [更多 ▾]|
| [搜索专栏______]      │  文章 4 · 阅读次数 3,236 · 阅读人数 890 · 点赞 156 · 评论 21|
|----------------------+-------------------------------------------------------|
| ● AI产业研究 (4)      |  标题     | 状态   | 发布时间 | 阅读次数|阅读人数|点赞|评论| 操作   |
|   港股观察 (6)        |  宏观大盘… | 已上架 | 09-24.. | 3,236  | 890   |156| 21 | 详情… |
|   债券入门 (2)        |  券商软件… | 草稿   | -       | -      | -     | - | -  | 详情… |
|   理财入门 (0)(置灰)   |                                                |
+------------------------------------------------------------------------------+
```

### 4.2 专栏目录区

#### 4.2.1 目录列表

- 目录区顶部为「专栏目录」标题和「+ 新建专栏」文字按钮。
- 标题下方为「搜索专栏」输入框，按专栏名称模糊过滤；无匹配时显示「未找到相关专栏」。
- 每个专栏节点显示专栏名称和文章数，如「AI产业研究 (4)」。
- 点击专栏节点，右侧工作区切换为该专栏内容，节点呈选中态。
- 已下架的专栏在目录中标题弱化显示，仍可点击进入。
- 专栏支持拖动排序：按住专栏节点上下拖动，落点以上下边线指示插入位置，松开即完成调整，顺序即时保存并有 toast 提示；顺序对 C 端左侧目录同步生效（见 3.3.1）。
- 搜索过滤期间（输入关键词）暂停拖动，清空搜索后恢复；新建专栏默认排列在目录最前。

#### 4.2.2 新建 / 编辑专栏弹窗

点击「+ 新建专栏」打开新建弹窗；点击工作区的「编辑」按钮打开编辑弹窗（回显当前专栏信息）。

**原型示意**：

```
+----------------------------------------------+
|  新建专栏                              [×]   |
|----------------------------------------------|
|  * 专栏名称                                  |
|  [________________________]                  |
|  （必填，最多 20 字）                          |
|                                              |
|  专栏简介                                    |
|  [________________________________________]  |
|  （选填，最多 60 字）                          |
|                                              |
|              [ 取消 ]      [ 保 存 ]          |
+----------------------------------------------+
```

**(1) 字段说明**

a. 专栏名称：必填，文本，最多 20 字。输入前后空格自动过滤；保存时校验是否与其他专栏重名，重名时在输入框下方提示「该专栏名称已存在」。

b. 专栏简介：非必填，文本，最多 60 字。

**(2) 保存逻辑**

点击「保存」校验通过后关闭弹窗，左侧目录刷新。新建的专栏默认状态为「已上架」，文章数为 0，C 端左侧目录同步出现该专栏；保存成功有 toast 提示。点击「取消」或「×」或点击弹窗外遮罩均关闭弹窗，不保存。

#### 4.2.3 专栏上架 / 下架 / 删除

- 专栏状态分为「已上架」「已下架」，在工作区标题旁以标签展示。
- 上下架入口在「更多 ▾」下拉菜单中，按当前状态显示「下架」或「上架」。上下架均无需二次确认；下架后 C 端目录立即不再显示该专栏及其全部长文，重新上架后恢复，数据不变。
- 「更多 ▾」下拉中的「删除」项，点击后二次确认：「删除专栏将同时删除其下全部长文，且不可恢复，确认删除？」确认后专栏及其下全部长文从后台和 C 端同步移除；删除后自动选中目录中第一个专栏。

### 4.3 专栏工作区

#### 4.3.1 标题区与操作按钮

**原型示意**：

```
+------------------------------------------------------------------+
| AI产业研究  [已上架]                     [写文章] [编辑] [更多 ▾]  |
|------------------------------------------------------------------|
| 文章 4 · 阅读次数 3,236 · 阅读人数 890 · 点赞 156 · 评论 21         |
+------------------------------------------------------------------+
（「更多 ▾」展开：[ 下架 ] [ 删除 ]）
```

- 左侧为专栏名称与状态标签；右侧为操作按钮组：「写文章」（主按钮，进入长文编辑器，见第 5 章）、「编辑」（打开专栏编辑弹窗）、「更多 ▾」（上下架与删除，见 4.2.3）。

#### 4.3.2 汇总数据行

- 标题区下方一行展示当前专栏的汇总数据：文章、阅读次数、阅读人数、点赞、评论，以「·」分隔。
- 各项为该专栏下全部文章对应数据的累加；阅读次数等计数直接显示完整的具体数字，不做 k/w 缩写。
- 数据来源与计数口径：
  a. 阅读次数：C 端文章阅读页每次打开计 1 次，同一用户重复打开累计计算；
  b. 阅读人数：按用户去重，同一用户多次阅读只计 1 人；
  c. 点赞、评论：实时数据，取消点赞、删除评论同步扣减；
  d. 文章上下架不影响统计数据：已下架文章保留历史数据，仍计入专栏汇总，重新上架后数据不变；
  e. 后台长文详情抽屉的预览不计入阅读数据。
- 汇总数据仅供运营参考，C 端不展示。

### 4.4 长文列表

#### 4.4.1 表格

**原型示意**：

```
+--------------------------------------------------------------------------+
| 标题                    | 状态   | 发布时间          | 阅读次数| 阅读人数| 点赞| 评论| 操作            |
|-------------------------|--------|-------------------|--------|--------|-----|-----|-----------------|
| 宏观大盘的指标分析已经…    | 已上架 | 2026-09-24 18:30 | 3,236  | 890    | 156 | 21  | 详情 编辑 下架 删除|
| 券商行情软件横评：谁更…    | 草稿   | -                | -      | -      | -   | -   | 详情 编辑 上架 删除|
| 美股行情质量跟踪周报       | 已下架 | 2026-09-20 10:12 | 1,123  | 320    | 45  | 8   | 详情 编辑 上架 删除|
+--------------------------------------------------------------------------+
                                              [< 1 2 3 >] 共 12 条    ← 每页 20 条
```

- 列说明：
  a. 标题：最多显示两行，超出省略；点击标题打开长文详情抽屉（见 4.5）。
  b. 状态：以标签展示草稿、已上架、已下架三种状态。
  c. 发布时间：格式如 2026-09-24 18:30；草稿状态显示「-」。
  d. 阅读次数、阅读人数、点赞、评论：四个独立数据列，统计口径见 4.3.2；草稿状态四列均显示「-」，已下架保留历史数据显示。
- 列表排序：按长文排序号降序，排序号相同的按最近更新时间倒序。
- 操作列按钮左对齐，依次为：详情、编辑、下架（已上架）或上架（草稿/已下架）、删除。
- 专栏下没有文章时，表格区域显示空态卡片：「该专栏下暂无长文」+ 引导文案 + 「写文章」按钮。

#### 4.4.2 分页

- 默认每页 20 条，分页器展示总条数、上一页/下一页和页码。
- 只要列表有数据就显示分页器，仅空列表时隐藏。
- 切换选中专栏或列表数据变化时，回到第一页。

#### 4.4.3 行操作

- 详情：打开长文详情抽屉（见 4.5）。
- 编辑：进入长文编辑器并回显内容（见第 5 章）。
- 下架：仅已上架文章显示，需二次确认「下架后 C 端将不可见，确认下架《标题》？」；确认后文章对 C 端不可见。
- 上架：草稿和已下架文章显示「上架」按钮，点击立即上架、无需确认；草稿首次上架时记录发布时间。
- 删除：需二次确认「删除后 C 端将不可见且不可恢复，确认删除《标题》？」；确认后文章从后台和 C 端同步移除。
- 以上操作完成后均有 toast 提示。

### 4.5 长文详情抽屉（后台嵌入预览）

点击列表中的标题或「详情」按钮，右侧滑出抽屉预览文章；点击「×」或抽屉外遮罩关闭。

**原型示意**：

```
                                            +-------------------------------+
                                            | 文章详情 · 宏观大盘指标…   [×] |
   （点击遮罩关闭抽屉）                        |-------------------------------|
                                            |                               |
                                            |  （内嵌 C 端文章阅读页）        |
                                            |  星主身份全文可见、无会员遮罩    |
                                            |  不显示左侧导航与目录树          |
                                            |  不显示上一篇/下一篇导航         |
                                            |                               |
                                            |  评论区每条评论悬浮显示删除按钮  |
                                            +-------------------------------+
                                            ← 自右侧滑入，宽约占视口三分之二
```

- 抽屉标题为「文章详情 · 文章标题」，右上角「×」关闭。
- 抽屉内直接内嵌 C 端专栏阅读页（自动定位到对应专栏和文章），因此阅读页的排版、正文渲染与 C 端完全一致。
- 预览规则：
  a. 以星主身份打开，全文直接可见，不显示会员遮罩、付费卡片与开通弹窗；
  b. 只呈现文章阅读区本身，不显示 C 端左侧导航与专栏目录树，也不显示上一篇/下一篇导航卡片；
  c. 抽屉内浏览不写入本机已读记录，避免污染浏览数据。
- 评论治理：评论区每条评论悬浮时显示删除按钮（不限评论者），点击后二次确认「确认删除「昵称」的这条评论？删除后不可恢复。」；确认后该评论从 C 端同步移除，评论计数减一。
- 草稿和已下架文章在 C 端不可见，但后台仍可通过抽屉预览全文并治理评论。

## 5. 管理后台：长文编辑器

### 5.1 编辑器页面布局

点击「写文章」或列表「编辑」后，进入整页长文编辑器，不显示后台左侧菜单。

**原型示意**：

```
+----------------------------------------------------------------------+
| ← 返回          写文章                        [存草稿] [保存并上架]    |
|----------------------------------------------------------------------|
|                                                                      |
|   请输入标题（最多 50 字）                        ← 标题输入      |
|                                                                      |
|   所属专栏 [AI产业研究 ▾]   主笔作者 [Rich  ▾]   排序 [0________]     |
|----------------------------------------------------------------------|
| ↺ ↻ │ B I U S │ H2 H3 正文 │ •列表 1.列表 │ 引用 代码 │ 左 中 右 │    |
| 链接 图片 分割线 │ 文字颜色 ▾ │ 清除格式          ← 工具栏吸顶悬浮      |
|----------------------------------------------------------------------|
|                                                                      |
|   从此处开始撰写正文…                                                 |
|   （富文本编辑区，正文区限宽居中）                                       |
|                                                                      |
+----------------------------------------------------------------------+
```

- 顶栏：左侧「返回」按钮回到专栏管理页；中间显示页面标题（新建为「写文章」，编辑为「编辑长文」）；右侧为保存按钮组。
- 保存按钮组规则：
  a. 新建文章，或编辑草稿/已下架文章时，显示「存草稿」「保存并上架」两个按钮；
  b. 编辑已上架文章时，显示「存草稿」「保存修改」两个按钮。
- 正文区限宽居中，标题未输入时显示占位文案。

### 5.2 字段说明

a. 标题：必填，文本，最多 50 字。C 端阅读页将标题独立展示为文章主标题，正文无需重复书写标题。

b. 所属专栏：必填，下拉单选，仅列出「已上架」的专栏。点击专栏工作区「写文章」按钮新建时，自动将当前选中的专栏带入（仅当该专栏为已上架状态）；若当前专栏为已下架，则不带入默认值，由用户手动选择。编辑文章时可更换所属专栏（转移专栏），保存后原专栏与新专栏的文章数同步增减，C 端两侧目录同步更新。

c. 主笔作者：非必填，下拉选择星球成员（含星主、合伙人、嘉宾、会员、普通成员），支持按昵称搜索，已选后可一键清空。C 端阅读页作者行显示该昵称，未选择时 C 端不显示作者信息行（仅显示发布时间）。

d. 排序：非必填，数字，默认 0；负数或未填写按 0 处理。数字越大越靠前，同时决定后台列表顺序与 C 端目录顺序；排序号相同的按最近更新时间倒序兜底。

e. 正文：上架时必填，富文本编辑（见 5.3）。

### 5.3 富文本工具栏

工具栏吸附在编辑区顶部，滚动时保持可见。功能按分组排列：

| 分组    | 功能                          |
| ----- | --------------------------- |
| 撤销重做  | 撤销、重做                       |
| 字格式   | 加粗、斜体、下划线、删除线               |
| 段落    | 章节标题（H2）、小节标题（H3）、正文段落      |
| 列表    | 无序列表、有序列表                   |
| 引用与代码 | 引用块、代码块                     |
| 对齐    | 左对齐、居中、右对齐                  |
| 插入    | 链接、图片、分割线                   |
| 颜色    | 文字颜色（提供黑、红、橙、黄、绿、蓝、紫、灰八种颜色） |
| 其他    | 清除格式（去除所选文字的全部样式，保留纯文本）     |

- 插入链接：点击后弹出输入框填写链接地址，确认后对所选文字生成超链接。
- 插入图片：见 5.4。

### 5.4 图片插入与粘贴处理

- 本地插图：点击工具栏图片按钮，从本地选择图片（支持一次多张），按顺序插入正文光标位置；图片宽度自适应正文宽度。
- 图片尺寸调整：插入后的图片支持用鼠标拖拽调整大小（等比缩放），以手动调整的尺寸为准，随保存生效并由 C 端按该尺寸展示。
- 截图粘贴：复制截图后直接在正文粘贴，图片自动插入正文。
- 外部网页粘贴：从外部网页（如公众号文章）复制内容粘贴时，自动净化后插入——剔除网页中的全部图片（含二维码、统计像素等隐藏图片）以及脚本、样式等杂质，仅保留文字排版。如需使用原文章图片，通过工具栏「图片」按钮手动插入本地图片。

### 5.5 保存与上架逻辑

- 「存草稿」：校验标题、所属专栏必填，未填时 toast 提示；保存为草稿，C 端不可见，列表状态变为「草稿」。编辑已上架文章时点击「存草稿」，文章也由「已上架」变为「草稿」，C 端下线，原有阅读、点赞、评论等数据保留。
- 「保存并上架」：校验标题、所属专栏、正文必填（主笔作者非必填），未填时 toast 提示对应内容；上架后文章在 C 端专栏内立即可见，首次上架记录发布时间。
- 「保存修改」（编辑已上架文章）：保存后文章保持「已上架」状态，实时同步 C 端，无需重新上架。
- 编辑已下架文章时保存并上架，文章恢复为「已上架」状态，数据保留。
- 保存成功后返回专栏管理页，并有 toast 提示（如「长文《XX》上架成功，C 端已可见」「已保存为草稿，C 端不可见」「长文修改已保存，C 端实时同步」）。
- 转移专栏保存成功时，额外提示「长文已转移至专栏「XX」」。
- 备注：编辑器「返回」暂不做未保存校验，未保存内容会直接丢失；后续版本计划增加未保存提示或自动存草稿。
