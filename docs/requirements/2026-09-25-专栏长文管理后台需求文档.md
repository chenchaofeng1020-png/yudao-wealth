## 1. 概述

### 1.1 背景

C 端「专栏」模块已经上线：用户在专栏页按目录阅读投研长文，可以点赞、评论、分享，未开通会员的用户（星友）只能试读正文开头部分。管理端目前只有一个简单的维护原型，存在几个明显的缺口：长文保存后立即对 C 端可见，没有草稿和下架能力；评论没有治理入口；运营数据没有地方看。

本文档规划管理后台「内容中心」中专栏长文模块的完整管理能力，页面路径为 `/cms/content`，在现有「左侧专栏树 + 右侧详情」页面结构上迭代，长文列表调整为后台标准表格风格。

### 1.2 目标

- 管理员可以在后台完成专栏和长文的全生命周期管理：新建 → 编辑 → 发布 → 下架 → 删除。
- 管理端管理的字段与 C 端实际展示完全对齐：C 端已经隐藏的元素（精华标识、话题标签、字数、收藏、举报等）不再出现在管理端表单和列表中。
- 评论可治理：管理员可以删除违规评论，删除后 C 端同步移除。
- 运营可以在后台查看专栏和长文的阅读、点赞、评论数据。

### 1.3 功能模块范围

| 大模块 | 子模块 | 功能板块 | 功能点描述 |
|---|---|---|---|
| 内容中心 | 专栏管理 | 专栏目录树 | 树形展示、长文数量统计、新建/编辑专栏 |
| 内容中心 | 专栏管理 | 专栏状态管理 | 上架/下架、删除（含二次确认） |
| 内容中心 | 长文管理 | 长文列表 | 标准表格、状态筛选、关键词搜索 |

| 内容中心 | 长文管理 | 状态流转 | 草稿 / 已发布 / 已下架 |

## 2. 页面布局总览

## 3. 专栏管理

### 3.1 专栏目录树

左侧目录树展示全部专栏，每个节点显示专栏名称和该专栏下的长文数量徽标。目录上方展示「共 X 个专栏」的统计，并提供「+ 新建专栏」按钮。

- 专栏按创建时间倒序排列，最新创建的显示在最上方。
- 点击专栏节点，右侧切换为该专栏的详情区。
- 本期不提供专栏搜索（专栏数量有限），仅提供长文关键词搜索（见 4.1）。

### 3.2 新建 / 编辑专栏

点击「+ 新建专栏」或专栏详情区的「编辑」按钮，打开专栏编辑弹窗。

**原型示意**：

```
+----------------------------------------------+
|  新建专栏                              [×]   |
|----------------------------------------------|
|  * 专栏名称                                  |
|  [________________________]                  |
|  (必填，最多 20 字)                           |
|                                              |
|  专栏简介                                    |
|  [________________________________________]  |
|  (选填，最多 60 字，展示于 C 端专栏页)         |
|                                              |
|              [ 取消 ]      [ 保 存 ]          |
+----------------------------------------------+
```

**(1) 字段说明**

a. 专栏名称：必填，文本，最多 20 字。输入框失焦时自动过滤前后空格；保存时校验是否与其他专栏重名，重名则在输入框下方红色提示「该专栏名称已存在」。

b. 专栏简介：非必填，文本，最多 60 字。本期 C 端专栏页暂不展示该字段，为后续专栏频道页预留。

**(2) 保存逻辑**

点击「保存」时校验必填项和重名，通过后关闭弹窗、刷新左侧目录树；新建的专栏默认状态为「已上架」，长文数为 0，C 端左侧目录同步出现该专栏（空专栏在 C 端显示「暂无收录长文」）。

### 3.3 专栏上架 / 下架 / 删除

- 专栏状态分为「已上架」「已下架」，在详情区标题旁以标签展示；下架的专栏在目录树中置灰。
- 下架：点击「下架」后无需二次确认（可通过「上架」随时恢复），C 端左侧目录立即不再显示该专栏及其全部长文。
- 上架：下架的专栏可随时重新上架，C 端恢复展示，长文与评论数据不变。
- 删除：点击「删除」弹出二次确认：「删除专栏将同时删除其下全部长文，且不可恢复，确认删除？」确认后专栏及长文从管理端和 C 端同步移除。

## 4. 长文管理

### 4.0 业务流程

长文的生命周期围绕「草稿 → 发布 → 下架」三个状态展开，评论治理贯穿已发布阶段：

```
新建/编辑长文
   │
   ├─ 存草稿 ──► 【草稿】──发布──► 【已发布】──下架──► 【已下架】
   │              ▲                              │
   │              └──────────重新发布─────────────┘
   │
   └─ 删除（三种状态均可删，二次确认，不可恢复）

说明：已发布状态下编辑保存实时同步 C 端，无需重新发布；
     草稿、已下架对 C 端不可见，重新发布后阅读、点赞、评论数据保留。
```

各状态的可见性与允许操作见 4.3 状态流转表；评论治理不改变长文状态，仅删除单条评论（见第 5 章）。

### 4.1 长文列表

长文列表改为后台标准表格：斑马纹行底色、状态用标签展示、操作按钮右对齐。列表仅展示当前选中专栏下的长文。

- 筛选区：状态下拉（全部 / 草稿 / 已发布 / 已下架，默认「全部」）+ 关键词搜索框（按标题模糊匹配）。
- 状态标签配色约定：草稿为灰色、已发布为绿色、已下架为橙色，与资讯管理列表风格保持一致。
- 列表默认按最近更新时间倒序排列，草稿与已发布混合展示。
- 每行展示：标题（超长省略，悬浮显示全文）、状态标签、发布时间（草稿显示「-」）、数据（阅读·点赞·评论，草稿显示「-」）、操作按钮。
- 操作按钮：阅读（打开详情弹窗）、编辑、发布（草稿/已下架状态）或下架（已发布状态）、评论、删除。
- 删除需二次确认：「删除后 C 端将不可见且不可恢复，确认删除？」。

**原型示意**：

```
+--------------------------------------------------------------------------+
| 状态[全部 ▾]   关键词[搜索长文标题______]                   [发布新长文]    |
|--------------------------------------------------------------------------|
| 标题                    | 状态   | 发布时间      | 数据       | 操作       |
|-------------------------|--------|---------------|------------|------------|
| 宏观大盘的指标分析已经…   | 已发布 | 2026-09-24 18:30 | 3.2k·98·21 | 阅读 编辑 |
|                         |        |               |            | 下架 评论 删除 |
| 券商行情软件横评：谁更…   | 草稿   | -             | -          | 阅读 编辑 |
|                         |        |               |            | 发布 评论 删除 |
| （斑马纹交替行，操作右对齐，标题列左对齐限 2 行）                              |
+--------------------------------------------------------------------------+
```

### 4.2 新建 / 编辑长文弹窗

点击「发布新长文」或列表中的「编辑」打开弹窗，弹窗设置最大高度并支持内部滚动。

**原型示意**：

```
+------------------------------------------------------------+
|  发布新长文                                          [×]   |
|------------------------------------------------------------|
|  * 标题                                                    |
|  [__________________________________________]              |
|                                                            |
|  * 所属专栏                    * 主笔作者                  |
|  [美股投研实战 ▾]               [Rich____________]         |
|                                                            |
|  * 正文 (Markdown)                  [编辑] [预览]          |
|  +------------------------------------------------+       |
|  | ## 一、市场状态                                 |       |
|  | 广度、风险与仓位……                              |       |
|  |                                                |       |
|  +------------------------------------------------+       |
|                                                            |
|  风险提示                                                  |
|  [风险提示：市场有风险，投资需谨慎____________]              |
|                                                            |
|              [ 存草稿 ]         [ 保存并发布 ]              |
+------------------------------------------------------------+
```

**(1) 字段说明**

a. 标题：必填，文本，最多 50 字。C 端阅读页将标题独立展示为文章主标题。

b. 所属专栏：必填，下拉单选，仅列出「已上架」的专栏。编辑已发布长文时允许转移专栏，保存后原专栏长文数减一、新专栏加一，C 端两处目录同步更新。

c. 主笔作者：必填，文本，C 端作者行显示该昵称与默认头像。

d. 正文：必填，Markdown 编辑器，支持「编辑 / 预览」切换。C 端标题已单独展示，正文无需重复书写标题。

e. 风险提示：非必填，文本，默认值「风险提示：市场有风险，投资需谨慎」，展示于 C 端正文底部。

**(2) 保存逻辑**

点击「存草稿」：校验标题和所属专栏必填，保存为草稿，C 端不可见，列表状态变为「草稿」。
点击「保存并发布」：校验全部必填项，未填的输入框下方红色提示；发布后 C 端专栏内立即出现该长文，发布时间记录为当前时间。
编辑「已发布」长文时底部按钮为「保存修改」，修改实时同步 C 端；下架操作在列表操作列完成。

**(3) 与旧原型的字段差异**

C 端已隐藏以下展示，本期表单和列表相应取消这些字段：话题标签、精华标识、置顶、免费试读开关、预估字数。后续若 C 端恢复展示再评估补充。

### 4.3 状态流转

| 状态 | 进入方式 | C 端可见性 | 允许的操作 |
|---|---|---|---|
| 草稿 | 存草稿 | 不可见 | 阅读、编辑、发布、评论、删除 |
| 已发布 | 保存并发布 / 重新发布 | 专栏内展示、可阅读 | 阅读、编辑、下架、评论、删除 |
| 已下架 | 列表「下架」 | 不可见 | 阅读、编辑、发布、评论、删除 |

- 下架不删除数据，重新发布后数据（阅读、点赞、评论）保留并恢复展示。
- 已发布的长文编辑保存后实时同步 C 端，无需重新走发布流程。

### 4.4 阅读权益规则

- 星友（未开通会员）：仅可阅读正文前 20%，正文底部展示付费墙卡片：「本文余下内容为会员专享 · 开通会员解锁全文 ¥1,299/年」，点击按钮弹出开通会员弹窗。C 端现有的「按段落预览」逻辑同步调整为按正文 20% 比例截断。
- 会员及以上（会员、合伙人、嘉宾、星主）：免费阅读全文。
- 试读比例固定为 20%，本期不提供按篇调整的能力。
- 专栏定价（价格、特惠价）本期不在管理端开放维护，列为未来交付。

## 5. 评论治理

评论治理在长文详情弹窗内完成，不设独立评论管理页签。

- 入口：长文列表操作列「评论」按钮，打开详情弹窗（居中弹窗、最大高度内部滚动），上半部分为正文只读预览，下半部分为评论列表。
- 每条评论展示：用户头像、昵称、评论时间、评论内容；评论右侧提供红色「删除」按钮。
- 删除需二次确认：「删除后该评论将从 C 端同步移除，确认删除？」；确认后评论及楼中楼回复一并移除，C 端评论计数减一。
- 草稿和已下架长文的评论 C 端不可见，但管理端仍可进入弹窗查看并删除。

**原型示意**：

```
+------------------------------------------------------------+
|  长文详情 · 宏观大盘的指标分析已经完结                [×]   |
|------------------------------------------------------------|
|  （正文只读预览，超出部分弹窗内滚动）                        |
|------------------------------------------------------------|
|  评论（21）                                                 |
|  [头像] Rich   2026-09-24 18:30                    [删除]  |
|  宏观指标分析已完结，接下来是行业拆解！                        |
|------------------------------------------------------------|
|  [头像] Emily  2026-09-24 21:23                    [删除]  |
|  券商行情软件有哪些？                                        |
+------------------------------------------------------------+
```

## 6. 数据概览

数据概览为运营内部参考，C 端不展示阅读数等数据。

- 专栏维度：详情区顶部一行汇总卡，展示长文数、累计阅读、累计点赞、累计评论、订阅数（订阅数只读，本期不可编辑）。
- 长文维度：列表「数据」列展示「阅读 · 点赞 · 评论」三项计数；草稿长文不展示（显示「-」），已下架长文保留历史数据展示。
- 本期仅做数据展示，不做趋势图表（列为未来交付）。

## 7. 非功能性需求

- 页面风格沿用后台标准：斑马纹表格、标签式状态、操作按钮右对齐；管理页面不使用 C 端绿色自定义风格。
- 弹窗统一设置最大高度并支持内部滚动；删除、下架等操作提供二次确认；操作结果统一 toast 反馈。
- 权限：仅管理员角色可见「内容中心」，普通角色不可见入口。
